## 单次记录模板（复制使用）

```markdown
## YYYY-MM-DD　【场景一句话】

- **场景**：需要新增 XX（Controller + ApplicationService + Repository + 迁移脚本）
- **使用的 Skill**：module-generator
- **AI 初次产出**：生成了 XxxController，但把 Y 校验写在了 Controller 里，
  且 Repository 接口直接定义在 infrastructure 层
- **我的修正**：
  1. 把校验规则下沉到 Xxx 领域实体的构造方法
  2. Repository 接口上移到 domain 层，infrastructure 只保留实现
- **为什么**：Controller 承担业务规则会导致该规则无法在批量导入场景复用；
  接口留在基础设施层会让 domain 依赖具体实现，破坏依赖倒置
- **对 Skill 的改进**：在「强制约束」补第 5 条，在「常见错误」补了这个反例
```
