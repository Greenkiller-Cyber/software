## 工具脚本

```bash
# 分层依赖校验（违反四层架构规则时返回非 0）
python 02-开发Skill/module-generator/scripts/check-layering.py 03-源码/backend/src/main/java

# 扫描代码结构，生成模块清单供文档回填
python 02-开发Skill/arch-doc-sync/scripts/scan-structure.py 03-源码/backend/src/main/java -o structure.md

# 生成项目脚手架 / 结构自检
python 02-开发Skill/project-scaffold/scripts/init-project.py --name <名称> --package <包名> --dry-run
python 02-开发Skill/project-scaffold/scripts/init-project.py --verify
```

| 说明书篇幅 | 40–70 页 |

| Skill | ≥3 个，每个带可执行资产 |

| 演示视频 | 5–8 分钟，有口播 |
