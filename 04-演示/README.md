## 1 视频三段结构（缺一段 −2 分）

| 段落 | 时长 | 内容要求 | 自检 |
|------|------|---------|------|
| ① 架构讲解 | ~2 min | 对着图讲架构（不是念文档），必须说明**最重要的 3 个架构决策及理由** | ☐ |
| ② 功能演示 | ~3 min | 按角色演示核心流程，覆盖 **≥6 个功能模块**，至少 1 个 C2 状态流转 + 1 个 C3 异步场景 | ☐ |
| ③ 代码走查 | ~1.5 min | 打开 IDE，说明"逻辑视图的模块在代码哪个位置"，证明文档与代码一致 | ☐ |

## 2 录制检查清单

- [ ] 1080P、MP4、≤300MB
- [ ] 全程有口播（纯录屏 + 字幕 −3 分）
- [ ] 口播清晰、无长时间静音
- [ ] 演示数据真实、不虚构

## 3 截图清单（≥12 张）

| 类别 | 张数 | 内容 |
|------|------|------|
| 核心界面 | ≥6 | 各角色主要流程 |
| 架构图效果 | ≥2 | 渲染后的架构图 |
| 部署后台 | ≥2 | 服务器 / 容器状态 |
| 监控日志 | ≥2 | 日志、指标面板 |

## 4 答辩准备

- 现场演示 5 分钟 + 问答 5 分钟，**全体组员参与**
- 问答重点：架构决策理由 / 视图一致性 / AI 使用边界 / 核心代码为什么这么写
- 红线：回答不出"某段核心代码为什么这样写"的，该模块功能分按 0 计
