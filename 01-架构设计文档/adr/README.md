## 写作要求

每条 ADR 必须回答三个问题：**为什么需要决策？有哪些备选？为什么选它、放弃其他？**

写完一条后，把状态从「提案」改为「已接受」，并在设计说明书 §2.4 的汇总表中同步状态。
